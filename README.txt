WIRE Automations website

Free publishing with GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository, for example: wire-automations.
3. Upload all files from this folder (index.html, style.css, script.js, images folder).
4. Open repository Settings > Pages.
5. Under Build and deployment choose Deploy from a branch.
6. Branch: main, folder: / (root), then Save.
7. GitHub will show the live website address after deployment.

Do not upload only the ZIP file; upload the files/folders inside it.
